### Exercice Lire une fable

<details markdown="1">
<summary>Voir la correction</summary>

Le programme affiche la fable avec une ligne vide après chaque ligne, comme dans l'exemple du § 8.3.1 : chaque ligne renvoyée par `readlines()` se termine déjà par `\n`, et `print` en ajoute un second. Pour l'éviter, on utilise `print(ligne, end="")`.

```python
# 1. Imports section
# No import needed

# 2. Functions section
# No functions in this exercise

# 3. Main routine section
if __name__ == "__main__":
    mon_fichier = open("fable.txt", "r", encoding="utf-8")  # open the file in read mode
    liste_lignes = mon_fichier.readlines()  # list of str, each one ends with '\n'
    mon_fichier.close()  # always close the file once it has been read

    for ligne in liste_lignes:
        # end="" avoids adding a second '\n' after the one already in the line
        print(ligne, end="")
```

### Exercice Copier une fable

<details markdown="1">
<summary>Voir la correction</summary>

Rien ne s'affiche dans la console : la fonction `copie` lit toutes les lignes de `fable.txt` avec `readlines()` puis les écrit avec `writelines()` dans un nouveau fichier `fable_copie.txt`, créé dans le même dossier (le mode `"w"` écrase le fichier s'il existe déjà).

La copie fait la même taille que l'original : **702 octets** sur Mac et Linux. Sous Windows, elle fait 703 octets, car le fichier de destination est ouvert sans `encoding="utf-8"` : les 16 lettres accentuées sont écrites sur 1 octet au lieu de 2, et les 17 sauts de ligne `\n` deviennent `\r\n`. Pour obtenir une copie identique, on précise l'encodage aussi à l'écriture :

```python
# 1. Imports section
# No import needed


# 2. Functions section
def copie(source, destination):
    """
    Fonction qui copie les lignes du fichier source dans le fichier destination
    et renvoie le nombre de lignes copiées
    """
    file_in = open(source, "r", encoding="utf-8")  # open the source in read mode
    lignes = file_in.readlines()  # read all the lines
    file_in.close()

    # "w" creates the file (or overwrites it if it already exists)
    file_out = open(destination, "w", encoding="utf-8")
    file_out.writelines(lignes)  # write all the lines
    file_out.close()

    return len(lignes)


# 3. Main routine section
if __name__ == "__main__":
    nb_lignes = copie("fable.txt", "fable_copie.txt")
    print(f"{nb_lignes} lignes copiées dans fable_copie.txt")
```

### Exercice fichiers

<details markdown="1">
<summary>Voir la correction</summary>

```python
# 1. Imports section
# No import needed


# 2. Functions section
def lire_lignes(nom_fichier):
    """
    Fonction qui renvoie la liste des lignes du fichier nom_fichier
    """
    fichier = open(nom_fichier, "r", encoding="utf-8")
    lignes = fichier.readlines()
    fichier.close()
    return lignes


def compte_nb_lignes(nom_fichier):
    """
    Fonction qui renvoie le nombre de lignes du fichier nom_fichier
    """
    return len(lire_lignes(nom_fichier))


def affiche_no_ligne(nom_fichier):
    """
    Fonction qui renvoie le texte du fichier, chaque ligne étant
    précédée par son numéro
    """
    texte = ""
    numero = 1
    for ligne in lire_lignes(nom_fichier):
        # each line already ends with '\n', so the lines stay separated
        texte += str(numero) + " : " + ligne
        numero += 1
    return texte


def decoupe(nom_fichier):
    """
    Fonction qui renvoie, pour chaque ligne du fichier, la liste de ses mots
    """
    liste_mots = []
    for ligne in lire_lignes(nom_fichier):
        # split() without argument cuts on spaces and removes the '\n'
        liste_mots.append(ligne.split())
    return liste_mots


# 3. Main routine section
if __name__ == "__main__":
    # Test on two different files
    for nom in ["fable.txt", "fichier_vide.txt"]:
        print(f"Le fichier {nom} a {compte_nb_lignes(nom)} lignes.")

    print(affiche_no_ligne("fable.txt"))

    for mots in decoupe("fable.txt"):
        print(mots)
```

### Exercice Données sur le maïs - PRO

<details markdown="1">
<summary>Voir la correction</summary>

Avec le module `csv` de la bibliothèque standard :

```python
# 1. Imports section
import csv


# 2. Functions section
def lire_csv(nom_fichier):
    """
    Fonction qui renvoie l'entête et les données d'un fichier CSV
    dont le séparateur est '\t', en utilisant le module csv
    """
    # "with" closes the file automatically, even if an error occurs
    with open(nom_fichier, "r", encoding="utf-8", newline="") as fichier:
        lecteur = csv.reader(fichier, delimiter="\t")
        entete = next(lecteur)  # first line: the column names
        data = list(lecteur)  # the remaining lines, each one is a list of str
    return entete, data


def afficher_contenu_csv(nom_fichier):
    """
    Fonction qui renvoie un texte contenant pour chaque ligne son numéro,
    puis pour chaque colonne le nom de la colonne et la valeur
    """
    entete, data = lire_csv(nom_fichier)
    texte = ""
    # enumerate gives the line number and the line at the same time
    for numero, ligne in enumerate(data, start=1):
        texte += f"ligne {numero} :\n"
        # zip associates each column name with its value
        for nom_colonne, valeur in zip(entete, ligne):
            texte += f"\t{nom_colonne} = {valeur}\n"
    return texte


def extraire_colonne(nom_fichier, j):
    """
    Fonction qui renvoie le nom de la colonne j et la liste de ses valeurs
    """
    entete, data = lire_csv(nom_fichier)
    return entete[j], [ligne[j] for ligne in data]


# 3. Main routine section
if __name__ == "__main__":
    print(afficher_contenu_csv("donnees_mais.txt"))

    rendement, valeurs_rendement = extraire_colonne("donnees_mais.txt", 3)
    print(rendement)
    print(valeurs_rendement)
```

### Exercice Graphiques

<details markdown="1">
<summary>Voir la correction</summary>

Trois graphiques classiques : un histogramme pour la distribution d'une variable quantitative, des boîtes à moustaches pour comparer cette variable entre les variétés, et un nuage de points pour la relation entre deux variables quantitatives.

```python
# 1. Imports section
import matplotlib.pyplot as plt
import pandas as pd

# 2. Functions section
# No functions in this exercise

# 3. Main routine section
if __name__ == "__main__":
    df = pd.read_csv("donnees_mais.txt", sep="\t")
    varietes = sorted(df["Variete"].unique())

    fig, axes = plt.subplots(1, 3, figsize=(16, 5))

    # 1. Histogram: distribution of one quantitative variable
    axes[0].hist(df["Rendement"], bins=20, edgecolor="black")
    axes[0].set_title("Distribution du rendement")
    axes[0].set_xlabel("Rendement")
    axes[0].set_ylabel("Nombre de lignées")

    # 2. Boxplot: compare a quantitative variable between groups
    rendements_par_variete = [df[df["Variete"] == v]["Rendement"] for v in varietes]
    axes[1].boxplot(rendements_par_variete)
    axes[1].set_xticks(range(1, len(varietes) + 1), varietes, rotation=30)
    axes[1].set_title("Rendement par variété")
    axes[1].set_ylabel("Rendement")

    # 3. Scatter plot: relation between two quantitative variables
    for v in varietes:
        sous_df = df[df["Variete"] == v]
        axes[2].scatter(sous_df["Floraison"], sous_df["Feuilles"], label=v, s=15)
    axes[2].set_title("Feuilles en fonction de la floraison")
    axes[2].set_xlabel("Floraison")
    axes[2].set_ylabel("Feuilles")
    axes[2].legend()

    plt.tight_layout()
    plt.show()
```
